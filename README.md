# Solve The Unsolved

Solve The Unsolved is an Android detective game where players investigate virtual crime scenes, collect evidence, analyze witness statements, and identify the culprit.

## Features
- User registration and login with Firebase Authentication
- Multiple criminal cases
- Evidence collection system
- Suspect profiles
- Witness statements
- Case-solving mechanics
- Sensor integration (Light Sensor)

## Technologies
- Kotlin
- Jetpack Compose
- Firebase Authentication
- Firebase Firestore
- Android Sensors
